# Sales-Analysis-Business-Intelligence-Dashboard-
This project is an interactive Business Intelligence Dashboard developed using Power BI to analyze and visualize sales performance data. The dashboard provides a comprehensive overview of key business metrics, enabling users to monitor sales trends, evaluate employee performance, and make data-driven decisions.
Key Features
Interactive dashboards with dynamic filters and slicers for customized analysis.
KPI tracking including Total Sales, Target Achievement, and Performance Metrics.
Regional and employee-wise sales performance analysis.
Data cleaning, transformation, and modeling using Power Query.
Visualizations such as charts, graphs, and summary reports for effective business reporting.
Actionable insights to support strategic decision-making and performance improvement.
Tools & Technologies
Power BI
Power Query
DAX
Microsoft Excel
